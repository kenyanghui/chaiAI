本节的逻辑

第 1 节名字已指向一个 IP，这个 IP 现在还是空的。本节买下那台机器（Hermes 轻量服务器），登进去装 nginx，放一个 index.html，写一条 vhost 把域名映射到页面——浏览器输域名，站就活了。讲师的 hundun / dedao / zhicheng.aibay.asia 三个站，跑的就是这套结构。

server 块最小骨架（抄这个）

server {
    listen 80;
    server_name www.你的域名;
    root /data/mysite;
    index index.html;
}

第 2 节过关线

过关 = 以下四条全亮
☐ ssh root@IP 能登　☐ nginx -t 通过　☐ nginx -s reload 无报错　☐ 浏览器（域名或 IP）能打开页面

避坑四条

  • 改配置永远 nginx -t 通过再 reload：-t 报错说明语法有坑，硬 reload 会把服务弄挂。
  • 浏览器打不开先分锅：ssh 能登 = 服务器活着；IP 能开域名不能开 = 解析或备案；都不开 = 防火墙端口。
  • root 目录指错层级最常见：root 指到 /data/mysite，不是 index.html 文件本身。
  • 密码忘了别慌，控制台「重置密码」一分钟搞定，重置后重启实例生效。
