本节的逻辑

http 是明信片，https 是加锁信封。本节给站上锁（证书 + 443 + 301），再验证同一台服务器加第二个站只要复制 vhost 改两行——这就是讲师 hundun / dedao / zhicheng.aibay.asia 同机多站的全部秘密。

第二站 ☐

443 块骨架（抄这个）

server {
    listen 443 ssl;
    server_name www.你的域名;
    ssl_certificate /etc/nginx/ssl/你的域名.crt;
    ssl_certificate_key /etc/nginx/ssl/你的域名.key;
    root /data/mysite;
    index index.html;
}
server {
    listen 80;
    server_name www.你的域名;
    return 301 https://$host$request_uri;
}

注意：443 生效前提是域名已备案（大陆服务器 443 也会拦未备案域名）；没下证的先留 http 调试，备案过了再回来加锁。

避坑四条

  • 免费证书一年到期，到期日写进日历，忘了续 = 全站弹「不安全」。
  • 证书路径写错 nginx -t 就报错——报错信息里会写哪个文件打不开，照着查。
  • 301 是「http 块里跳 https」，别写反方向，否则永远锁不住。
  • 多站之间 server_name 必须不同：两份 conf 都写同一个 server_name，nginx 会拿默认站顶包，排障两眼一黑。
