七条验收线（打勾式）

✓验收项怎么验（命令/动作）怎么算过
☐① 域名解析生效 dig www.你的域名 +short 返回你的服务器 IP，与解析记录一致
☐② 服务器 ssh 能登 ssh root@你的IP 进到 root@主机名 的命令行，能敲命令
☐③ nginx 配置合法 服务器上 nginx -t 回显 test is successful（无 error）
☐④ http 域名能开 浏览器开 http://www.你的域名（未备案用 IP） 看到自己的 index.html 页面内容
☐⑤ https 锁标志 浏览器开 https://www.你的域名 地址栏锁标志亮起，无「不安全」提示
☐⑥ 301 生效 浏览器输入 http:// 地址 地址栏自动变成 https:// = 跳转成功
☐⑦ 第二个站 10 分钟加出来 计时：建目录 → cp vhost → 改 server_name/root 两行 → reload 第二个域名/子域浏览器能打开，全程 ≤ 10 分钟

两条常见「假通过」

  • ④ 用 IP 开通过 ≠ 域名通过——备案/解析问题只在域名路径暴露，务必用域名验一次（未备案期间允许 IP 替代，备案过了补验）。
  • ⑥ 手动加 https 前缀 ≠ 301 生效——必须是输 http 后自动变 https 才算。
