root 是什么

服务器上的最高权限账号——相当于你成了这台电脑的"管理员"。

钥匙只在你手里：密码别外传、别贴群。能进去，就要对它负责。

域名、解析、备案：三个词一次分清

锚点 1

域名 = 门牌

在腾讯云注册（选名 → 实名 → 购买），一年几十块，买断的是"这个名字归你用"。

锚点 2

解析 = 路标

加一条 A 记录，把域名指向你的公网 IP——生效后域名打开 = IP 打开。

锚点 3

备案 = 登记

大陆地域服务器对外提供网站服务须 ICP 备案：订单 → 腾讯云初审 → 管局审核。审核期间用 IP 照常访问。
