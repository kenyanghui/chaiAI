备开始之前：设备与账号自查

本场三个工具：WorkBuddy 出脚本、剪映做成片、视频号助手排日程。先自查，缺什么课前补什么。

你需要有怎么确认已有没有怎么办
WorkBuddy打开 www.workbuddy.cn 下载安装，注册并登录，能新开一个对话没有：课前装好（免费），现场网络挤
剪映（电脑版或手机版）剪映首页能看到「图文成片」入口；电脑版在首页上方功能栏，手机版在首页「图文成片」卡片找不到入口：先升级到最新版再看；电脑版首页没有就点「更多功能」找
视频号助手浏览器打开 channels.weixin.qq.com，用微信扫码登录，能进「内容管理 → 发布视频」页登录不上：换电脑版微信重扫码；当天不行先用手机微信「视频号 → 发表」代替
微信（发视频号用）手机微信 我 → 视频号 能打开自己的视频号主页没有视频号：现场带你开通
（可选）拆页素材带 2–3 段你熟悉的拆书金句或便签，第 1 节直接用没带：现场发拆页样例，先跑通再说
剪映手机版和电脑版都行：图文成片两边都有，电脑版排字幕更省力，手机版导出更顺手——用你顺手的那个。工具版本更新快，入口名字以你手里的版本为准，找不到就用首页搜索框搜「图文成片」。

1第 1 节 · 金句变脚本：AI 写，你把关

本节目标：把一段拆页金句交给 WorkBuddy，产出一条 60 秒口播脚本，人工改到能上口｜预计 55 分钟

动手前确认：WorkBuddy 已登录；手上有一段金句（拆页原文或自带的素材）。
把金句和拆页背景喂给 WorkBuddy
  • 打开 WorkBuddy，新开一个对话
  • 复制这段：「我要做一条 60 秒拆书短视频。原文金句如下，帮我先复述一遍这句金句，再列 3 个可以展开的角度，先别写脚本。」
  • 粘贴到 WorkBuddy 对话框 → 把你的金句和出处（书名/拆页编号）接在冒号后面 → 发送
  • 收到的回复里挑 1 个你最想讲的角度，记在纸上
电脑版WorkBuddy 对话框直接粘贴；金句多段就一次贴全，别分几条发
手机版长按输入框粘贴；金句提前存在备忘录里，现场直接复制
检查点（看到才算做对）：WorkBuddy 回复里有金句复述和 3 个角度，你圈定了 1 个
没看到怎么办：回复跑题或太长：追加一句「只要角度，不要展开」，让它重出一版
让 WorkBuddy 按选定角度写 60 秒口播脚本
  • 复制这段：「按第 2 个角度写一条 60 秒口播脚本：开头 10 秒钩子、中间 40 秒讲透这句金句、结尾 10 秒给一个明天的微行动。口语，短句，不要书面腔。」
  • 粘贴到 WorkBuddy 对话框 → 把「第 2 个角度」改成你圈定的那个 → 发送
  • 对照三条自查：开头 3 句内有没有钩子；全篇短句、念着顺口；结尾有具体微行动
电脑版脚本直接全选复制，下一步贴给剪映用
手机版点住脚本文字全选复制；太长分两段复制
检查点（看到才算做对）：一条 150–200 字的口播脚本，念一遍不超过 60 秒，三条自查全过
没看到怎么办：念着超时：回「压到 150 字以内，钩子保留」；书面腔重：回「每个句子不超过 15 个字，重写」
人工把关：改到自己能一口气念完
  • 把 WorkBuddy 给的脚本里最像「AI 腔」的三处圈出来（套话、重复、太满的句子）
  • 每处手动改成自己的话——这步别交给 AI，你的语气就是视频的辨识度
  • 改完出声念一遍全程计时，卡壳的地方再顺一遍
电脑版改完存进备忘录或文档，第 2 节直接用
手机版存在备忘录命名为「金句脚本 01」，成片时直接调用
检查点（看到才算做对）：出声念完不卡壳、不超 60 秒，圈出的三处都改成了自己的话
没看到怎么办：怎么改都有 AI 腔：挑一段你自己说过的话（便签、群聊记录）贴给 WorkBuddy，回「照这个语气重写脚本」

本节排障表（4 个常见卡点）

症状可能原因解法
WorkBuddy 回复很慢或转圈现场网络挤、高峰限流等一轮；还不行就把对话新开一个重发，别在原对话里反复催
生成的脚本像公众号文章不像口播指令里没限制句式追加「口语、短句、每句 15 字以内」，AI 默认输出书面体
金句太短，AI 硬凑了 200 字素材信息量不够在喂料时补两句你自己的经历（什么场合读到、当时想到什么），AI 就有东西可讲
手机上复制脚本带上了编号和竖线直接长按选中了整段回复分两段选中纯文字部分复制，或让 WorkBuddy 重发一遍「只发脚本正文」

2第 2 节 · 脚本变成片：图文成片，一次成片

本节目标：把定稿脚本贴进剪映「图文成片」，产出一条带字幕配音的成片并导出｜预计 60 分钟

动手前确认：剪映已登录（手机版/电脑版都行）；定稿脚本在手（第 1 节产出）。
脚本贴进剪映「图文成片」
  • 打开剪映
  • 电脑版：首页上方功能栏点「图文成片」；手机版：首页点「图文成片」卡片
  • 选「粘贴链接」旁边的「自定义输入」框 → 把第 1 节定稿的脚本整段粘进去 → 点「生成」
  • 生成方式如果让你选，选「AI 匹配素材」——先看机器出的第一版
电脑版剪映首页 → 图文成片 → 自定义输入 → 粘贴 → 生成；生成约 1–2 分钟
手机版剪映 App 首页 → 图文成片 → 自定义输入 → 粘贴 → 生成；耗流量，连 Wi-Fi 再跑
检查点（看到才算做对）：剪映生成了一条 60 秒左右、带字幕和 AI 配音的草稿
没看到怎么办：提示字数超限：回 WorkBuddy 让它压到 150 字再生成；生成失败：换「自定义输入」重试一次，别用粘贴链接
把关修改：换配音、删空镜
  • 点时间轴上的「文本」轨道通读一遍字幕——错别字当场改
  • 「朗读」里试听 2–3 个音色，选一个跟你气质接近的，别用默认第一个
  • 通看一遍画面：跟内容明显不符的片段，点中段「替换素材」，换剪映素材库搜出来的更贴的
  • 开头 3 秒单看一遍——观众划不划走就看这 3 秒
电脑版字幕在右侧编辑面板逐条改；替换素材右键片段 → 替换素材
手机版点字幕条直接改字；点片段 → 替换 → 搜素材关键词
检查点（看到才算做对）：通片看完无错别字、配音听着不尬、开头 3 秒有钩子
没看到怎么办：AI 匹配的画面大量跑偏：别逐段修，把「AI 匹配」换成「本地素材」模式，用自己的书页照片当底，字幕叠加
导出成片，命名归档
  • 点右上角「导出」，分辨率 1080P 就够，导出到本地
  • 文件命名「金句01-书名-日期」，存进你建好的「成片」文件夹
  • 从头到尾看一遍导出的成片——导出后偶有音画不同步，看一眼放心
电脑版导出到 成片/ 文件夹；文件大的话发微信用「文件传输助手」传到手机
手机版导出自动存相册；发视频号时直接从相册选
检查点（看到才算做对）：成片文件已导出，能从头到尾流畅播放，命名规范
没看到怎么办：音画不同步：导出设置里把帧率改成 30fps 重新导出；手机发烫卡顿：退出剪映重开再导出一次

本节排障表（4 个常见卡点）

症状可能原因解法
图文成片生成到一半失败脚本里有敏感词或网络波动把脚本里品牌名、链接删掉再试；还不行新开一次自定义输入
AI 配音听着别扭默认音色太「播音腔」「朗读」里换「知性女声/磁性男声」等贴近真人的音色；语速调到 1.1 倍更自然
字幕和语音对不上脚本里的括号、书名号被当成正文念了把脚本里的括号、破折号删净再生成；或生成后在文本轨道手动断句
电脑版导出的视频传不到手机没登录同一账号或没用文件传输助手电脑微信发「文件传输助手」，手机微信同账号直接收；别用网盘来回倒

3第 3 节 · 排进发布日程：视频号 + 素材库

本节目标：把成片排进视频号发布日程，建一个源源不断进料的素材库，定下 30 天更新节律｜预计 45 分钟

动手前确认：视频号助手能扫码登录；手机微信能打开自己的视频号。
成片发上视频号（先用「定时发布」体验一次排程）
  • 浏览器打开 channels.weixin.qq.com，微信扫码登录
  • 左侧「内容管理」→「发布视频」→ 上传你的成片
  • 封面选视频里字最清楚的一帧；标题写金句本身；话题带 #拆书 #书名
  • 发布方式选「定时发布」，设到明天早上 7:30——先体验一次排程，明天看它自动上线
  • 发布成功后截图贴到群里
电脑版视频号助手网页直接传电脑导出的成片，最顺
手机版微信 我 → 视频号 → 右上角相机 → 从相册选成片 → 发表；定时发布在发表前「更多设置」里
检查点（看到才算做对）：视频号后台「内容管理」里能看到一条「定时中」的视频，群里已贴截图
没看到怎么办：上传卡住：先发一条 10 秒测试视频走通流程再传正式的；提示账号异常：手机端先发一条再回电脑端
建素材库：让金句源源不断
  • 对 WorkBuddy 说：「帮我在 ima 里建一个『短视频素材库』目录，分三个子目录：金句 / 活动预告 / 学员便签。」
  • 把今天用过的金句脚本放进「金句」目录——第一件藏品入库
  • 定一条收集规矩：今后每拆一页、每办一场活动、每收到一张好便签，当天丢进对应目录，不整理只丢入
  • 再对 WorkBuddy 说：「扫一遍素材库，按『钩子感』排个优先级清单发我。」
电脑版ima 网页版 ima.qq.com 建目录；WorkBuddy 指令直接发对话框
手机版ima App 同名同路径；便签类素材手机随手拍随手传
检查点（看到才算做对）：素材库三目录建好、金句目录有 1 条、拿到一份优先级清单
没看到怎么办：WorkBuddy 连不上 ima：检查 ima 设置 → 开放 API 的 Client ID 和 API Key 是否还有效，过期就在那页重置一份
定 30 天更新节律并写进计划
  • 打开材料 04（30 天短视频更新计划），三栏当场写满：素材来源、每周条数、自查日
  • 节律建议从「每周 2 条」起步——AI 出稿你把关，2 条大约每周花你 2 小时
  • 把每周固定的制作时段写进日历（比如周三晚、周日晚），跟计划对齐
  • 写完拍一张照发到群里——说出口的计划才会真的发生
电脑版计划表打印手填最有感觉；拍照上传群相册
手机版备忘录建「短视频 30 天」清单，三栏照抄，每周日晚上勾一次
检查点（看到才算做对）：三栏写满、日历有固定制作时段、计划拍照已发群
没看到怎么办：写不出每周条数：退一档，先定「每周 1 条」，30 天后跑稳了再加——先让产线活着

本节排障表（4 个常见卡点）

症状可能原因解法
视频号助手扫码后白屏浏览器兼容问题换 Chrome 或 Edge 重开；还不行直接用手机微信「视频号 → 发表」发，功能不缺
定时视频第二天没发出去设定时间处于审核中或素材被判违规早上看一眼「内容管理」状态；审核中会顺延发出；被退回就换封面标题重提

ima 建目录失败API 配置过期ima 设置 → 开放 API 里重置 Client ID / API Key，贴给自己的 WorkBuddy 重连——key 只贴给自己的 WorkBuddy，别发群里

逐项打勾，全勾 = 这场工作坊的成果你已真实拥有。建议每勾一项截一张图存相册，那就是你的完成凭证。

续30 天巩固计划（自助版）

工作坊的成果 30 天不用就会忘。每周一小步，周末 5 分钟自查没掉队。

时间做什么怎么自查没掉队
第 1 周每周 2 条起步：从素材库挑 2 条金句，走完 脚本→成片→排程 全流程视频号后台本周有 2 条上线；素材库库存没断
第 2 周维持 2 条，开始试同一脚本换两种开头钩子，看哪条完播率高两条视频的开头 3 秒不同；看完播数据记一笔
第 3 周加一条非金句内容（活动预告或学员便签），验证素材库的另外两个目录三类内容各上线过至少 1 条
第 4 周复盘月度数据：留下完播最高的那类内容，30 天计划升级成下一版一次 30 分钟月度复盘；下一版计划写好并拍照发群
卡住怎么办（按顺序试）
1. 重读当前步骤的「检查点」和本节排障表——90% 的卡点都在里面；
2. 把你看到的界面截图保存下来，对照排障表找「症状」一栏；
3. 还不行：带上截图来微信群问，微信 ikoning365（点击不了就手动复制添加）。
