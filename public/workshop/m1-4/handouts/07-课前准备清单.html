工具四件（缺一开场就落后）

✓工具自查到什么程度没有怎么办
☐WorkBuddywww.workbuddy.cn 下载安装，注册登录，能新开对话课前装好（免费）；当天装会挤
☐剪映（电脑版或手机版）首页能看到「图文成片」入口升级到最新版再找；电脑版首页没有就点「更多功能」
☐视频号助手浏览器开 channels.weixin.qq.com 扫码能登录，进「内容管理 → 发布视频」页换电脑版微信重扫码；当天不行手机微信「视频号 → 发表」代替
☐微信（视频号）手机微信 我 → 视频号 能打开自己主页没有视频号：现场带你开通

素材（有备无患）

✓物品说明
☐2–3 段金句素材你熟悉的拆页金句/好书金句/便签，存备忘录；没带现场发拆页样例
☐（可选）自己的一段语音或聊天记录第 1 节「照我的语气重写」用，有它脚本更像你
☐（可选）耳机试听配音音色用

账号安全（做完别外传）

· 微信扫码登录视频号助手，登完就关页面，别在公用电脑勾「记住登录」。
· ima 开放 API 的 Client ID / API Key 只贴给自己的 WorkBuddy，绝不发群、不发朋友圈截图。

开课前 10 分钟到场做三件事

① 连现场 Wi-Fi，开 WorkBuddy 发一句「你好」确认能回复；② 开剪映确认「图文成片」入口在；③ 扫码登视频号助手截个图存着——三绿开场，全场不慌。
