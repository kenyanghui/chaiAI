边界怎么写（三问过关）

钥匙问：哪把钥匙（密码 / 授权码 / API Key）它要用？只给必需那把。动作问：哪类动作必须先经你批（发布 / 花钱 / 删东西）？写进边界就是审批门。
失控问：它跑飞了最多损失多少？——月度预算封顶，超限自动停。

为什么会卡住（自查）

不知设多少预算 → 用月度愿意付的上限起手，课后随时调。汇报连不上 → 确认两个 agent 都在成员列表里；卡住举手，助教 30 秒能解决。

A1 / A2 + 换成你的场景（拆为己用 · 三问）

A1：团队新来的实习生第一天，你会给他哪些权限、藏起哪些钥匙？　A2 便签：本周内，把   岗位预算定为 ¥  ，把   这把钥匙只发给它。

三问：① 课堂示例是"内容专员 + 资料整理员"——我对应的岗位是？  ② 先做的一件小事（如先连一条汇报线）？  ③ 明天第一步做什么（几点、打开什么）？ 

名词一句话卡：组织架构图＝一张写清"谁向谁汇报"的公司图，人和 agent 同图；权限边界＝这个岗位能干什么、绝不能干什么；钥匙（secret）＝密码 / 授权码 / API Key 这类"开门凭证"；月度预算＝每个 agent 每月最多花多少钱，到顶自动停。
