边界怎么写（三问过关）

钥匙问：哪把钥匙（密码 / 授权码 / API Key）它要用？——只给岗位必需的那把，其余一律不给。
动作问：哪类动作必须先经你批？（如：对外发布、花钱、删东西）——写进边界，就是审批门。
失控问：它跑飞了最多损失多少？——用月度预算封顶，超限自动停。

为什么会卡住（自查）

不知道设多少预算 → 用你月度愿意为这个岗位付出的上限起手，课后随时调。
岗位起不出三个 → 先两个（1 个干活 + 1 个整理），架构能跑就行，别硬凑。
汇报关系连不上 → 确认两个 agent 都已在成员列表里；卡住举手，助教 30 秒能解决。
