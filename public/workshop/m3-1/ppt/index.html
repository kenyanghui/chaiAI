安 + 装

先安家，再给脑子：两条铁律

第 1 节 · 安
服务器开机 + SSH 登入

控制台新建（Ubuntu 22.04）→ 记下你自己的公网 IP → ssh root@你自己的IP 登入 → apt 补丁一轮。

第 2 节 · 装
hermes + 模型 key

官方脚本安装 → hermes setup 向导 → hermes model 选模型（≥64K），key 落 ~/.hermes/.env。

铁律一（备份）：cd ~/.hermes && cp .env .env.bak-日期 ← 改前必做
铁律二（权限）：chmod 600 ~/.hermes/.env ← key 文件不给别人看

返回「正常」= 服务器 → hermes → 模型 → 回话，四环全通；hermes --continue 还能捡回会话。这就是交付 ② 的凭证。

然后

加本事
