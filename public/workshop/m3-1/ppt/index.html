WHY

为什么是「云服务器」

你手机上的 AI 再聪明，App 一关它就下班。有一台自己的服务器，你的数字员工才真正 7×24 在岗：

  • 它永远在线——关掉电脑、锁上手机，任务照跑到点不误

    3.1 云服务器构建数字助理04 / 10
    第 1 节 · 安家

    买一台服务器，登进去

    购买开机轻量应用服务器控制台 → 新建 → 就近地域 + Ubuntu LTS + 最轻入门档（规格价格以购买页当期显示为准）
    拿到三样身份公网 IP（你自己的服务器 IP）· root 密码（重置后私下存好）· 控制台详情页随时可查
    SSH 登录三选一A 详情页一键登录（最简）· B 云服务器 → Workbench（更稳）· C 本机终端 ssh root@你自己的服务器IP（课后主用）
    打招呼三条命令whoami（我是谁）· pwd（我在哪）· uptime（开机多久）——以后每次排障的基本功
    安全口径：密码只私下存；防火墙保持默认放行 22/80；密钥登录讲优点、不强制当场切换。
    3.1 云服务器构建数字助理05 / 10
    第 2 节 · 跑活

    第一个定时任务

    # ① 写脚本（nano 里就一行）
    echo "$(date '+%F %T') 数字助理在岗"

    # ② 挂定时（crontab -e 末尾加一行）
    0 9 * * * /root/bot/hello.sh >> /root/bot/hello.log 2>&1

    # ③ 不等明天：时间改成两分钟后，到点看日志
    cat ~/bot/hello.log
  • 口诀「分时日月周」：0 9 * * * = 每天 9 点，先抄先跑
  • 两分钟测试是本节高潮——日志多一行，就是服务器自己在干活
  • 日志加 2>&1，报错才看得见；排障三件套：crontab -l / 绝对路径 / date 对时区

    第 3 节 · 上线

    数字助理进群值守

    拿 Webhook企业微信群右上角「…」→ 群机器人 → 添加；或飞书群设置 → 群机器人 → 自定义机器人 → 复制地址（你自己的 Webhook 地址）
    值守脚本开口bot.sh 用 curl 向 Webhook POST 一条消息——群里「叮」一声，数字助理第一次说话
    workbuddy 加料「帮我把脚本升级成每天早报：日期、待办提醒、服务器运行时长」——你提要求，它写代码
    正式上岗crontab 换成 bot.sh 每天 9:00 → 三凭证发群交验收 → 明早 9 点见
    凭据红线：Webhook 地址只贴服务器脚本，不进群、不截图、不写进作业；万一误发——删消息、删机器人重建，旧地址作废即安全。
