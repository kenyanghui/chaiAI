1第 1 节 · 安：云服务器安家

本节目标：在腾讯云轻量应用服务器上开出一台自己的机器，并用 SSH 从自己电脑登进去｜预计 40 分钟

动手前确认：腾讯云账号已登录；浏览器能打开 console.cloud.tencent.com/lighthouse。
开机：买一台轻量应用服务器
  • 浏览器打开 console.cloud.tencent.com/lighthouse → 点「新建」
  • 地域选离你近的（如广州/上海）；镜像选系统类 · Ubuntu 22.04（课程统一口径，排障最快）
  • 规格选入门档即可（具体价格以当期招募页为准）；付款后 1–2 分钟状态变「运行中」
  • 在实例详情页记下两样：你自己的服务器公网 IP、你自己的登录密码（在「重置密码」处先设一个）
已有多台服务器任挑一台 Ubuntu 的用，不用新买
想用其他系统可以，但排障时请对照 Ubuntu 口径自己换包名
检查点（看到才算做对）：实例列表里这台机器状态为「运行中」，公网 IP 抄在本页底部
没看到怎么办：提示「库存不足」：换个地域再点新建；实名认证没过的先过认证
连通：从自己电脑 SSH 登录
  • 打开 SSH 终端（Windows PowerShell / Mac 终端），输入：ssh root@你自己的服务器公网 IP
  • 第一次连会问 are you sure，输 yes 回车；再输你自己的服务器密码（输入时屏幕不显示，正常）
  • 看到 root@… 这样的提示符就是登进来了
  • 把这条 ssh 命令记进手机备忘录，课后还要天天用
WindowsPowerShell 自带 ssh；提示「不是内部或外部命令」就去「设置→应用→可选功能」装 OpenSSH 客户端
Mac终端直接输 ssh 命令即可
检查点（看到才算做对）：终端里出现 root 开头的提示符，pwd 回车显示 /root
没看到怎么办：连不上：回控制台看防火墙是否放行 22 端口（默认放行）；密码错就去「重置密码」重设后重启实例
守门：给服务器立两条安全规矩
  • apt update && apt upgrade -y 打一轮系统补丁（几分钟，等它跑完）
  • 规矩一：控制台防火墙只保留 22（SSH），其余端口一律不开——hermes 的 gateway 是往外连消息平台，不需要对公网开新端口，也不教开危险端口
  • 规矩二：服务器密码只记在自己手机备忘录或密码管理器里，不发群、不写进任何文档；输错三次被锁就回控制台重置
想加密登录课后可配 SSH 密钥登录并关密码登录，课上先用密码统一口径
检查点（看到才算做对）：apt upgrade 无报错结束；防火墙页里没看到多余的放行端口
没看到怎么办：补丁装到一半断网：重新 ssh 登录再跑一遍 apt update && apt upgrade -y，会自动续上

2第 2 节 · 装：hermes 落地 + 模型接上

本节目标：在服务器上装好 hermes，用 setup 初始化、选对模型，让助理有脑子｜预计 50 分钟

动手前确认：已 SSH 登录服务器；手边有你自己的模型 API key。
装 hermes（官方安装脚本）
  • SSH 终端里执行：curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
  • 装完执行 source ~/.bashrc，让当前终端认得 hermes 命令
  • 安装目录在 ~/.hermes，配置和技能以后都住这里
  • 装完执行 hermes --version（或直接输 hermes 回车看有没有反应），能响应即装好
命令不识别先 source ~/.bashrc；还不行就退出 ssh 重登一次再试
检查点（看到才算做对）：终端输 hermes 有响应（出版本号或进入界面都算）
没看到怎么办：下载慢/超时：Ctrl+C 后重跑一遍安装脚本，一般第二次就过
初始化：跑 hermes setup
  • 执行 hermes setup 进入初始化向导，三种模式选一种：
  • Quick Setup（Nous Portal OAuth 网页一键登）、Full Setup（自带各家 key）、Blank Slate（最小化）——有自己 API key 的选 Full Setup
  • 只想最快跑通：hermes setup --portal 一条命令走 Nous Portal 登录
  • 向导让你填 API key 时，粘贴你自己的 API key（终端不回显，正常）
  • 国内 provider 对照：Z.AI（GLM，环境变量 GLM_API_KEY/ZAI_API_KEY）、DeepSeek（DEEPSEEK_API_KEY）、阿里 DashScope（DASHSCOPE_API_KEY）、Kimi（KIMI_API_KEY）
想换模式setup 可以重复跑，换模式重走一遍即可
检查点（看到才算做对）：setup 向导走完没有报错退出
没看到怎么办：向导中途退出：直接重跑 hermes setup，向导可重复进；怀疑环境坏掉先跑 hermes doctor 体检
选模型：hermes model 向导 + config 落盘
  • 执行 hermes model 进交互向导，按提示选 provider 和模型
  • 命令行直接设也行：hermes config set model anthropic/claude-opus-4.6（换成你选的模型名）——config set 会自动把配置落对文件
  • hermes 的配置分两个文件：密钥进 ~/.hermes/.env，非密钥进 ~/.hermes/config.yaml；用 hermes config set 不容易落错
  • 硬杠：模型上下文必须 ≥64K，不达标的模型 hermes 启动会直接拒——选型时认准长上下文款
  • 铁律：手改文件前先备份——cd ~/.hermes && cp .env .env.bak-1111 && cp config.yaml config.yaml.bak-1111；改完把 .env 权限收到 600：chmod 600 ~/.hermes/.env（key 文件不给别人看）
不惯用命令行改配置nano ~/.hermes/config.yaml 也能改，但密钥一律写 .env 不写 yaml
检查点（看到才算做对）：hermes config set 一条执行成功；ls ~/.hermes/ 里能看到 .env 和 config.yaml，.env 权限 -rw-------
没看到怎么办：config set 报错：多半是命令格式问题，对照 hermes config set <键> <值> 的写法重敲；改坏文件就 cp 备份复原

3第 3 节 · 跑：首聊冒烟 + 会话恢复

本节目标：在服务器上和 hermes 首聊成功，多轮不断、能调工具，会话断了还能 --continue 捡回来｜预计 45 分钟

动手前确认：hermes setup 已走完；hermes model 已选定 ≥64K 上下文的模型。
冒烟：第一次对话
  • SSH 终端执行：hermes（经典 CLI），或 hermes --tui 换图形界面款
  • 成功的标准有四条：横幅显示你选的模型、发「回复两个字：正常」能收到「正常」、让它查个东西能调工具、连问几句多轮不断
  • 把首聊截图发到课程群，这就是交付 ② 的第一张凭证
  • 再问一句业务话试试（比如「用一句话总结今天的日期」），确认不是只会说正常
返回慢首次调用模型有冷启动，等 10–20 秒；第二次起就快了
检查点（看到才算做对）：横幅显示模型名；「回复两个字：正常」收到「正常」；截图已发群
没看到怎么办：空回复/乱码：多半是 provider 或 model 选错，退出后重跑 hermes model 换一款再试
恢复：hermes --continue 捡回会话
  • 退出 hermes（按向导提示退出或 Ctrl+C），SSH 里再执行：hermes --continue
  • 它会把上一次的会话接着聊——数字助理的记性就靠这个
  • 日常习惯：断线重连后先 --continue，再继续交办任务
  • 想让助理多才多艺：hermes skills browse 看技能市集，hermes skills search <关键词> 搜、hermes skills install <名> 装，内置技能都在 ~/.hermes/skills/
找不到会话profile 换了或上次没正常保存；用 hermes sessions list 列出历史会话对号
检查点（看到才算做对）：hermes --continue 后它还记得上一句你说了什么
没看到怎么办：提示找不到会话：profile 换了/没保存——hermes sessions list 里找到对的会话再进；平时退出让它正常保存
体检：hermes doctor 过一遍
  • 执行 hermes doctor，让它把环境、配置、模型连通挨个查一遍
  • 全绿即健康；有黄项/红项按它给的提示逐条修，修完再跑一次 doctor 直到全绿
  • 记牢恢复工具链顺序：doctor → model → setup → sessions list → --continue → gateway status，出问题按这个链条捋，基本全能自救
  • 把 doctor 全绿截图存相册，这是你服务器的体检报告
doctor 报模型连不通回 hermes model 重选，或核对 .env 里 key 是否完整
检查点（看到才算做对）：hermes doctor 全绿无红项
没看到怎么办：doctor 修不动的项：截图发微信群，微信 ikoning365，讲师远程带看

4第 4 节 · 阵地：gateway 接消息平台，助理常驻

本节目标：用 hermes gateway 把 Telegram/企业微信群等接上，手机发消息、服务器上的助理回｜预计 45 分钟

动手前确认：首聊冒烟已通过；hermes doctor 全绿；手边有消息平台账号。
配通路：hermes gateway setup
  • SSH 终端执行：hermes gateway setup 进交互向导
  • 选你要接的平台：Telegram/Discord/Slack/WhatsApp/Signal/Email/Teams 都支持；国内场景常用 Telegram，或用 Email 通路过渡，企业微信群可在课后接兼容通路
  • 向导会让你填平台凭据（如 Telegram 的 Bot token）——一律填你自己的 Bot token，别用别人的、别发群
  • 配完执行 hermes gateway status 查状态，显示已连接即通路建成
  • 数字助理的真相：云服务器上跑着 hermes gateway 常驻接消息平台——人不在电脑前，助理在服务器上替你值守
用 Telegram先在 Telegram 里找 @BotFather 建一个 bot，拿到你自己的 Bot token 再进向导
检查点（看到才算做对）：hermes gateway status 显示你的平台已连接
没看到怎么办：gateway 起了但收不到消息：token/allowlist 不全——重跑 hermes gateway setup 补全，再 hermes gateway status 核对
验收：手机发一条，助理回一条
  • 手机上打开你的消息平台，给助理（你的 bot）发：回复两个字：正常
  • 几秒内收到「正常」，这条通路就是活的：手机→平台→服务器上的 hermes→模型→回话
  • 再发一句业务话（比如「帮我记一条待办：明早九点复盘」），确认能多轮
  • 两张截图合影发群：①hermes gateway status 已连接 ②手机上收到「正常」——这就是本场交付 ①②③
回复慢首次链路有冷启动；连续发几条观察是否稳定
检查点（看到才算做对）：手机发消息、助理秒级有回；两张截图已发群
没看到怎么办：手机没收到回复：按顺序查——hermes gateway status 是否连接 → 重跑 hermes gateway setup 核对 token/allowlist → hermes doctor 体检
值守：让它天天在岗
  • 重启服务器验证一次：控制台点重启 → 再 ssh 进来跑 hermes gateway status，通路还在就是真的常驻
  • 把恢复工具链贴在服务器备忘里：doctor → model → setup → sessions list → --continue → gateway status
  • 想给助理加本事：hermes skills browse 挑技能装上，内置技能都在 ~/.hermes/skills/
  • 每月一次小体检：hermes doctor 全绿 + gateway status 在线 + .env 权限还是 600
  • 讲师延伸一句：全新的 hermes setup 若检测到机器上有旧智能体，会提示一键导入旧配置（agent-importers 插件），感兴趣的同学课后自行了解
重启后 gateway 没起ssh 进来手动起一次 gateway，再跑 gateway status 确认；具体起法以向导提示为准
检查点（看到才算做对）：重启服务器后 hermes gateway status 仍显示连接；手机发消息仍有回
没看到怎么办：重启后失联：hermes doctor 逐项排查 → gateway setup 核对配置 → 还不行带截图来微信群，微信 ikoning365

续30 天巩固计划（自助版）

工作坊的成果 30 天不用就会忘。每周一小步，周末 5 分钟自查没掉队。

时间做什么怎么自查没掉队
第 1 周每天手机给助理发一句话验活；服务器上跑一次 hermes 首聊冒烟一周 7 天手机端都有回，其中至少一天是交办真实小任务
第 2 周把对话调得像你：多轮交代背景、用 --continue 接着聊；hermes skills browse 挑一个技能装上助理连续多轮记住上下文；新技能真的被用上一次
第 3 周加第二条通路或换更顺手的平台重走一遍 hermes gateway setuphermes gateway status 里多一条在线通路，换平台不怵
第 4 周做一次全面体检：hermes doctor 全绿、gateway status 在线、备份 .env 和 config.yaml、重启服务器验证常驻体检完三张截图（doctor/状态/手机对话）留档，数字助理满月在岗
