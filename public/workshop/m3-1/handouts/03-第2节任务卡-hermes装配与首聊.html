六步上线（逐项打勾）

✓时间动作我的记录
☐0–10′SSH 里装 hermes：curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash → 装完 source ~/.bashrc → 输 hermes 有响应即装好，安装目录在 ~/.hermeshermes 响应了 ☐
☐10–25′hermes setup 走初始化向导，三种模式：Quick Setup（Nous Portal OAuth）/ Full Setup（自带 key）/ Blank Slate（最小化）——有自己 key 的选 Full Setup；最快跑通也可 hermes setup --portal 一条命令走网页登录。让你填 key 时粘贴你自己的 API key（不回显，正常）选的模式： 
☐25–40′选模型：hermes model 交互向导选 provider 和模型（国内可用 Z.AI/DeepSeek/DashScope/Kimi）；或 hermes config set model <模型名>。配置双文件：密钥进 ~/.hermes/.env、非密钥进 ~/.hermes/config.yaml。铁律：改前先备份 cd ~/.hermes && cp .env .env.bak-日期 && cp config.yaml config.yaml.bak-日期 → 改完 chmod 600 ~/.hermes/.env。硬杠：模型上下文须 ≥64K，不达标启动直接被拒我选的模型： 
☐40–60′首聊冒烟：SSH 里输入 hermes（或 hermes --tui）→ 成功四条：横幅显示模型 / 发「回复两个字：正常」收到「正常」/ 让它查个东西能调工具 / 连问几句多轮不断 → 截图发群返回原文抄录： 
☐60–75′会话恢复：退出 hermes 后再执行 hermes --continue → 它还记得上一句你说了什么；找不到会话就 hermes sessions list 里对号。顺手 hermes skills browse 看一眼技能市集（技能都在 ~/.hermes/skills/）它记得的那句： 
☐75–95′体检：hermes doctor 挨项检查 → 全绿即健康，有红黄项按提示修到全绿 → 记牢恢复工具链：doctor → model → setup → sessions list → --continue → gateway status → doctor 全绿截图存相册doctor 全绿 ☐

卡住怎么办

hermes command not found → source ~/.bashrc 或重登 ssh；首聊空回复/乱码 → provider 或 model 选错，重跑 hermes model；启动被拒提示上下文 → 换 ≥64K 模型；--continue 找不到会话 → hermes sessions list 对号；都怪 → hermes doctor 按提示修。
