交付 ① 云服务器

✓验收标准
☐控制台实例状态「运行中」，我自己的服务器公网 IP 抄在手册上
☐ssh root@你自己的IP 一次登入成功，无需翻笔记
☐防火墙只放行 22（和 dashboard 端口），没有多余的开放端口

交付 ② openclaw 数字助理常驻

✓验收标准
☐~/.openclaw/ 里有 openclaw.json 且至少一个 .bak-日期 备份；文件权限 600
☐openclaw agent --agent main --message "回复两个字：正常" 返回「正常」
☐重启服务器后 openclaw gateway status 仍显示 active（真常驻）

交付 ③ cron 值守任务

✓验收标准
☐openclaw cron list 里至少一条任务，model 列显式设为你的模型名（不设会报 billing error）
☐群里收到过至少一条自动推送，时间点符合预期（注意服务器 UTC 与北京时差 8 小时）

安全底线（一票否决）

服务器密码与 API key 只存在你自己的备忘录/密码管理器，从没发群、没进截图。
