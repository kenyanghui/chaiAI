3.1 云服务器构建数字助理 · 控场与兜底（讲师/组长用）

资控节奏（210 分钟含开场复盘）

时段环节要点
0–10′开场三步走地图上墙；报名口径：非会员 39 元（含茶歇+资料）、会员免费、仅限 10 人、微信 ikoning365
10–50′第 1 节 安家人人买到「运行中」+ ssh 登入；卡实名/支付的安排拼机课后自购；凭证①收齐
50–100′第 2 节 装配安装脚本卡慢网就重跑一遍；hermes setup 向导可重进（Quick/Full/Blank 三模式口径统一 Full）；选模型盯两件事：上下文 ≥64K（不达标启动被拒）、国内 provider 对号（Z.AI/DeepSeek/DashScope/Kimi）；铁律盯备份：没 cp 不许动 .env 和 config.yaml；.env 权限 600 人人核
100–145′第 3 节 上线hermes 首聊「正常」是本节高潮，人人亲眼看返回；--continue 会话恢复别跳过；hermes doctor 全绿再放人进第 4 节；凭证②收齐
145–155′茶歇回看谁的 setup/key 卡住，组长先接
155–200′第 4 节 阵地hermes gateway setup 交互向导接平台（Telegram 最顺，Email 可作过渡）；头号坑=token/allowlist 不全：起不了消息就重跑 setup 补全再 gateway status 核对；手机发「正常」验收是硬动作；凭证③收齐
200–210′复盘合影复盘卡三问一诺；30 天计划发打卡表

头号坑速查（gateway 起了没消息）

学员 gateway 起了、手机收不到消息 = token/allowlist 不全。口诀直接给：hermes gateway status 看哪段断 → hermes gateway setup 重走补全凭据与 allowlist → 手机再发一条「回复两个字：正常」实测。配的时候整段复制 token 最省事。

兜底预案

① 付不了款 → 两人拼机完成后三节，课后自购复刻；② 地域缺货 → 释放换地域重建；③ 安装脚本全场慢 → Ctrl+C 重跑一遍，一般第二次就过；④ 空回复/乱码 → 重跑 hermes model 换 provider/模型组合；⑤ 平台实在配不通 → Email 通路兜底（gateway 支持 Email），课后换 Telegram 复刻。
