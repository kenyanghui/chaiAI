资控节奏（210 分钟含开场复盘）

时段环节要点
0–10′开场三步走地图上墙；报名口径：非会员 39 元（含茶歇+资料）、会员免费、仅限 10 人、微信 ikoning365
10–50′第 1 节 安家人人买到「运行中」+ ssh 登入；卡实名/支付的安排拼机课后自购；凭证①收齐
50–100′第 2 节 装配安装脚本双路线（curl/npm）兜慢网；onboard 向导可重进；铁律盯备份：没 cp 不许改 openclaw.json；权限 600 人人核
100–145′第 3 节 上线agent 冒烟「正常」是本节高潮，人人亲眼看返回；systemd 重启验证别跳过；dashboard 选做限时 15′；凭证②收齐
145–155′茶歇回看谁的 onboard/key 卡住，组长先接
155–200′第 4 节 阵地cron 建任务必显式设 model（头号坑）；时区换算黑板写一遍（北京早 8 点=UTC 0 点）；2 分钟短周期实测是验收动作；凭证③收齐
200–210′复盘合影复盘卡三问一诺；30 天计划发打卡表

头号坑速查（cron · billing error）

学员 cron 一跑报 billing error = 任务没显式设 model。口诀直接给：openclaw cron list 拿 id → openclaw cron edit <id> --model <模型名> → 人工触发验证。建任务时就显式设最省事。

兜底预案

① 付不了款 → 两人拼机完成后三节，课后自购复刻；② 地域缺货 → 释放换地域重建；③ 安装脚本全场慢 → 统一改走 npm 路线；④ webhook 不通 → 先用 cron list + 人工触发验证链路，群推送课后补；⑤ 明早 8 点没推送 → 让学员把 cron 任务的报错截图发群，远程带排障（九成是 model 没设或时区写反）。
