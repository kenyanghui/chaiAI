从「跑起来」到「天天在岗」· 每周一个动作 + 自查
3.1 · 材料 04

周计划（打印贴桌）

周做什么自查标准
第 1 周每天 ssh 登一次服务器跑 agent 冒烟；把任务 prompt 调成你的口吻7 天冒烟全「正常」，至少改过一版 prompt
第 2 周把推送内容做厚：加待办、加一句书摘；观察哪条真被用上每天的推送你自己会点开看，而不是划走
第 3 周加第二条 cron 任务（如周五下午推周报素材）；每条都显式设 model两条任务都在点，一周没出过 billing error
第 4 周全面体检：备份 openclaw.json、核对防火墙、重启服务器验证常驻体检三张截图（备份/端口/常驻）留档，助理满月在岗

每日一分钟点名（照抄即用）

ssh 登服务器 → openclaw agent --agent main --message "回复两个字：正常" → 见「正常」即点名完成。顺手 openclaw cron list 扫一眼任务都在、model 列没空。

最容易翻车的三处（提前打预防针）

症状一句话解法
cron 一跑报 billing error任务没显式设 model：openclaw cron edit <id> --model <你的模型名>
到点群里没动静先 date -R 查时区（UTC 差 8 小时），再 curl 测 webhook 通不通
改配置后助理起不来cp openclaw.json.bak-日期 openclaw.json 复原，只改 key 那一行再来
