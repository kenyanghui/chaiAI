30 天数字助理值守计划

从「跑起来」到「天天在岗」· 每周一个动作 + 自查
3.1 · 材料 04

周计划（打印贴桌）

周做什么自查标准
第 1 周每天手机给助理发一句话验活；服务器上跑一次 hermes 首聊冒烟一周 7 天手机端都有回，其中至少一天是交办真实小任务
第 2 周把对话调得像你：多轮交代背景、用 hermes --continue 接着聊；hermes skills browse 挑一个技能装上助理连续多轮记住上下文；新技能真的被用上一次
第 3 周加第二条通路或换更顺手的平台，重走一遍 hermes gateway setuphermes gateway status 里多一条在线通路，换平台不怵
第 4 周全面体检：hermes doctor 全绿、gateway status 在线、备份 .env 和 config.yaml、重启服务器验证常驻体检完三张截图（doctor/状态/手机对话）留档，助理满月在岗

每日一分钟点名（照抄即用）

手机给助理发「回复两个字：正常」→ 见「正常」即点名完成。隔几天 ssh 登服务器跑一遍 hermes gateway status 确认通路在线，再 hermes doctor 扫一眼环境健康。

最容易翻车的三处（提前打预防针）

症状一句话解法
助理回复空内容/乱码provider 或模型选错：重跑 hermes model 换正确的组合
gateway 起了、手机收不到消息token/allowlist 不全：重跑 hermes gateway setup 补全，再 hermes gateway status 核对
改配置后助理起不来cd ~/.hermes && cp .env.bak-日期 .env && cp config.yaml.bak-日期 config.yaml 复原，hermes doctor 体检后再来
