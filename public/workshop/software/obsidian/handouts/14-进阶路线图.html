二、进阶五站（每站 1–2 周，按需选装）

1
输入端 · Web Clipper 官方剪藏
网页、小红书、公众号一键剪进 00-痕迹——采集工作流的第一块拼图：先有任务 / 问题 / 表达欲，再去收集，剪藏自带出处和时间，正好接「痕迹只增不改」。
2
汇总 · Dataview 智能查询
让库自己长出仪表盘：按标签列笔记、汇总全库待办、日历显示笔记、提取当日新建。10-本体的人物 / 事件一页查询全出。
3
标准化 · Templater 模板
把起步模板包升级成按钮级流程：点一下出整套结构（人物页自动带别名 / 关系栏），整理动作从「记着怎么做」变成「点一下」。
4
库内 AI · Copilot 类插件
自备 API Key，在库内直接对话——关键一招：把 20-规则 的习惯笔记设为系统提示词。记住课上原则：它是「末梢」，换 AI 不换库，上下文永远是你的。
5
实战 · 三大 AI 场景
① 日记复盘 + AI：指令卡每周跑，月 / 年复盘让 AI 出结构化对比；② 读书笔记 + AI：摘要导入 → 摘录直接变笔记 → 汇总年度书单；③ 知识收集 + AI：剪藏进库后让 AI 把碎片关联到已有本体。

四、三大工作流（书模块五完整版）

GAP 的每一层都有自己的流水线。三本账是库，下面三条流水线让库自己转起来：

G
采集工作流：先有需求，再去收集
原则就一条：先有任务 / 问题 / 表达欲，再动手收集——为「以后可能有用」而存的，一律不存。
在哪看资源：固定 2–3 个信息源（公众号列表 / RSS / 优质社群），别到处乱刷；怎么写记录：剪藏或摘录时当场写一句自己的话（为什么剪它、想用它做什么），没想法的不剪；配置：Web Clipper 剪藏模板固定存 00-痕迹/收件箱，每日笔记模板加「今日输入」一栏；提效技巧：每天固定 10 分钟「收集窗口」以外不刷信息源；手机上看到 → 系统分享菜单一键进收件箱，晚上回来补那句自己的话。
A
整理工作流：定期清空收件箱
节奏：每周一次「清箱日」，四个动作按顺序走——① 处理未整理笔记：收件箱清零（删除 / 归档 / 转化，三选一，不许「留着再说」）；② 笔记关联：给新笔记挂 [[双链]]，至少连到一条已有本体；③ 整理归类：改标题成「一眼能认」的格式，按 GAP 归到对应层（痕迹 / 本体 / 规则）；④ 两个提效方法：顺手做，别开专门的「整理时间」——整理动作嵌进每周翻日记的既定动作里；一次只清一周的量，积压超过两周就砍掉最旧的（过期信息不值得整理）。
P
产出工作流：笔记 → 作品 → 公开
四步闭环：创建表达笔记（20-规则旁建「30-作品」，一篇作品一个文件，写清主题和目标读者）→ 完成表达（从双链拉素材进正文，AI 当草稿工，你改定稿）→ 整理笔记（发布版写完后，把新长出来的说法归一进本体，来源链接回作品）→ 公开表达（发公众号 / 知识星球 / 朋友圈，作品链接记回库里）。判断标准：库里 30 天内没有新作品，就是采集 / 整理在空转。

五、工作流可视化：看清整个知识地图

给库装仪表盘，四件套依次上：

件做法看到什么
① 标记笔记状态文件名前缀固定三态：【草稿】 / 【成品】 / 【已发布】每篇笔记处于哪一段，一眼定位
② 目录笔记每主题一页 MOC（Map of Content），双链挂全该主题的成品主题全景：库里有什么、缺什么
③ Dataview 查询按状态前缀自动出清单（草稿多少、成品多少、本周新增）仪表盘数字：不用翻文件夹就知道进度
④ Canvas 白板把 10-本体的人物 / 事件关系画成一张图（课前已装好的 Excalidraw 同理）知识地图：人和事的关系网看得见

工作流不是一次搭好，是拆成一连串小动作 + 模板，照着做就能跑起来。

终点提醒：知识库的终点是表达

GAP 的 P（Present）才是目的——每月从库里长出一篇能发出去的东西（文章 / 周报 / 短视频脚本），表达反哺采集方向。只进不出的库，迟早变坟场。
