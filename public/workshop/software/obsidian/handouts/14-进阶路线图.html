二、进阶五站（每站 1–2 周，按需选装）

1
输入端 · Web Clipper 官方剪藏
网页、小红书、公众号一键剪进 00-痕迹——采集工作流的第一块拼图：先有任务 / 问题 / 表达欲，再去收集，剪藏自带出处和时间，正好接「痕迹只增不改」。
2
汇总 · Dataview 智能查询
让库自己长出仪表盘：按标签列笔记、汇总全库待办、日历显示笔记、提取当日新建。10-本体的人物 / 事件一页查询全出。
3
标准化 · Templater 模板
把起步模板包升级成按钮级流程：点一下出整套结构（人物页自动带别名 / 关系栏），整理动作从「记着怎么做」变成「点一下」。
4
库内 AI · Copilot 类插件
自备 API Key，在库内直接对话——关键一招：把 20-规则 的习惯笔记设为系统提示词。记住课上原则：它是「末梢」，换 AI 不换库，上下文永远是你的。
5
实战 · 三大 AI 场景
① 日记复盘 + AI：指令卡每周跑，月 / 年复盘让 AI 出结构化对比；② 读书笔记 + AI：摘要导入 → 摘录直接变笔记 → 汇总年度书单；③ 知识收集 + AI：剪藏进库后让 AI 把碎片关联到已有本体。

三、工作流可视化：看清你的知识地图

书模块五的收口：给笔记标状态（草稿 / 成品）→ 建目录笔记 → Dataview 按状态出清单 → Canvas 白板把本体关系画成一张图（手册选装里的 Excalidraw 同理）。工作流不是一次搭好，是拆成一连串小动作 + 模板，照着做就能跑起来。

终点提醒：知识库的终点是表达

GAP 的 P（Present）才是目的——每月从库里长出一篇能发出去的东西（文章 / 周报 / 短视频脚本），表达反哺采集方向。只进不出的库，迟早变坟场。
