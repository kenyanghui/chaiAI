07 · 课前准备清单

5 分钟 · 三件事 · 不用预习任何知识
小蛮腰·拆AI
学员材料 · 开课前完成
总原则：本课是动手课，一切卡点 90% 出在「没装软件」。三件事做完，开课即起飞。

① 装 Obsidian + 建库（2′）

下载打开 obsidian.md → 选你电脑对应版本（Win / macOS / Linux，个人使用免费）
安装一路默认下一步
建库首次打开 → Create new vault → 名字「我的上下文」→ 放稳定位置（勿放桌面/下载）
自检能新建一条笔记并打字 ✓

② 开两个核心插件（1′）

入口左下齿轮 → 核心插件（不是社区插件）
打开日记 Daily notes + 模板 Templates 两个开关
格式日记日期格式保持默认（YYYY-MM-DD）
自检左侧日历图标能打开今天的日记 ✓
课上不用装任何社区插件（含 AI 插件）——指令卡与 Obsidian 解耦，这是刻意设计。

③ 备 2–3 份旧记录（2′）

找什么现成的日记 / 周报 / AI 聊天记录 / 会议纪要，任选 2–3 份
存哪存 .txt 或 .md，放电脑一个文件夹（第 1 节拖进库）
没有现写 3 条「今天发生了什么」也行
自检文件夹里有 2–3 份记录文件 ✓

带什么来

  • 电脑（装好上述软件）+ 电源
  • 一个能用的 AI 对话账号（WorkBuddy / Claude / ChatGPT，任一即可）
  • 远程同学：耳机 + 稳定网络，提前一天进群看会议链接
