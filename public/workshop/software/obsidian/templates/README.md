# 起步模板包 · Obsidian 三本账

第四期「让 AI 比你更懂你」彩蛋。四个文件，对应课上建的三层库：

| 文件 | 放到哪 | 干什么 |
| --- | --- | --- |
| `90-模板/日记模板.md` | vault 根的 `90-模板/` | 每日笔记模板（四栏）。设置 → 日记 → 模板文件位置填 `90-模板/日记模板` |
| `10-本体/人物模板.md` | `10-本体/` | 人物大事记 · 人物条目（别名/关系/相关） |
| `10-本体/事件模板.md` | `10-本体/` | 人物大事记 · 事件条目（别名/来龙去脉/相关） |
| `20-规则/习惯模板.md` | `20-规则/` | 我的习惯 · 规则条目（「以后遇到 __，就 __」+ 依据） |

## 用法（3 步）

1. 解压 zip，把 `00-痕迹 / 10-本体 / 20-规则 / 90-模板` 四个文件夹整个拖进你的 Obsidian vault（已有同名文件夹就只拖文件）。
2. 设置 → 日记 → 模板文件位置 填 `90-模板/日记模板`。
3. 点左侧日历图标打开今天的日记 → 右上「插入模板」，四栏出现即成功。

> 还没建库？先照[课前准备清单](../handouts/07-课前准备清单.html)装好 Obsidian，再照[自助跟做手册](../guide.html)第 1 节走一遍——模板包只是帮你跳过「手抄模板」那 5 分钟，三层骨架还是要自己建一遍，那正是课的重点。

每个模板文件里都带一行示例和用法说明，照着替换成你的内容即可。
