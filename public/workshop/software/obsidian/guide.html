Obsidian：让 AI 越用越懂我 自助跟做手册

3 节 · 约 145 分钟 · 建议边读边做，每一步都当场完成
做完这本手册，你会带走
  • 一个三层结构的个人上下文库（痕迹 / 本体 / 规则）
  • 一条「日记 → 归一 → AI 调用 → 回流」的工作流
  • 一份 30 天上下文养成计划 + 三张可复用的指令卡
「只有手机」的同学：Obsidian 没有手机端建库的顺畅路径，本课建议电脑完成；手机可以先读手册、收藏指令卡，回电脑再动手。第 3 节的指令卡推荐贴进 Obsidian Copilot（库内直接对话），贴给任意 AI 网页版也能用。

0开工前三件事（课前 5 分钟）

目标：装好软件、开好插件、备好素材。约 5 分钟

① 装 Obsidian + 建库
  1. 打开 obsidian.md，下载对应你电脑系统的版本（个人使用免费），一路默认安装。
  2. 首次打开 → 点 Create new vault → 名字填「我的上下文」→ 选一个放得稳的文件夹（不要放桌面/下载，避免清理时误删）。
  3. 能新建一条笔记、打上字，就完成。
✓ 验收：库里出现你建的第一条笔记。
② 打开两个核心插件
  1. 左下角齿轮（设置）→ 核心插件 → 打开 日记 Daily notes 和 模板 Templates。
  2. 日记日期格式保持默认（YYYY-MM-DD）。
  3. 点左侧栏日历图标，能打开今天的日记，就完成。
✓ 验收：点日历图标，弹出今天的日记页。
③ 备 2–3 份「旧痕迹」
  1. 找 2–3 份现成记录：日记、周报、和 AI 的聊天记录、会议纪要，都行。
  2. 存成 .txt 或 .md，放进电脑一个文件夹（第 1 节要导入）。
  3. 没有现成的？现在手写 3 条「今天发生了什么」也行。
✓ 验收：电脑里有个文件夹，躺着 2–3 份记录。
④ 装 Copilot 社区插件 + 配 DeepSeek（AI 进库，推荐；配置交给 WorkBuddy）
  1. 设置 → 社区插件 → 关闭安全模式 → 浏览 → 搜 Copilot → 安装并启用（插件主页：github.com/logancyang/obsidian-copilot）。
  2. 申请 DeepSeek API Key：platform.deepseek.com/api_keys → 注册 → 充值 10 元 → 创建 Key。本课统一用 DeepSeek，便宜够用。
  3. 把 Key 配进 Copilot 这步最容易卡（Windows 和 Mac 界面有差别：学员常找不到侧边栏图标，要在设置里手动开）——别自己折腾，直接交给 WorkBuddy：
    我要在 obsidian 里面用 opencode，我已经安装在 obsidian 的 copilot 里，你帮我配置 DeepSeek key：（粘贴你的 key）
  4. 配好点右侧栏 Copilot 图标，问「你好」能回就完成。聊天模式下拉里的 Vault QA 模式是本课主力——AI 直接读你的全库，全程免复制粘贴。
✓ 验收：Copilot 面板能对话。不装也能上课——指令卡贴 WorkBuddy / Claude / ChatGPT 等任意 AI 均可。
💡 本课以 Copilot 指令操作为主：Vault QA 模式让 AI 直接读库，第 2、3 节全程「说一句话、不搬文本」。WorkBuddy 全程做助教：装不上、配不对、看不懂——随时把报错或截图发它；建库也能提速，把项目文件/旧资料丢给 WorkBuddy 说「帮我整理成 markdown 导入 obsidian」，快速起步。没装 Copilot 的同学用讲义 12 的指令卡贴外部 AI（WorkBuddy / Claude / ChatGPT）也能完成，只是要手工粘贴。其余社区插件课后按需选装：手册末尾「社区插件四强」附官网链接。

1第 1 节 · 存：痕迹，发生过什么（建库）

目标：建出「痕迹 / 本体 / 规则」三个文件夹 + 每日笔记模板，导入旧记录。约 50 分钟

1.1 建三层骨架
  1. 左侧文件列表上方点「新建文件夹」，依次建三个：00-痕迹 10-本体 20-规则
  2. 编号前缀的作用：排序稳定、一眼分层。「00」最常写入，「20」最少动。
✓ 验收：文件列表出现三个文件夹。
1.2 配每日笔记（你的采集入口）
  1. 设置 → 日记 → 新建日记的存放位置 填 00-痕迹。
  2. 设置 → 日记 → 模板文件位置 先留空（1.3 建好模板后再回来填）。
从今天起，每天的事都只写进日记这一处——痕迹层「只增不改」：写错了新开一条更正，不回去改旧文。
1.3 建日记模板
  1. 新建文件夹 90-模板，在其中新建笔记 日记模板，内容照抄：
## 今天 - ## 和谁 - ## AI 帮我 / 我纠正 AI - ## 一句话存档 >
  1. 设置 → 日记 → 模板文件位置 填 90-模板/日记模板。
  2. 四栏的用意：「今天」记事；「和谁」记人；第三栏专记你对 AI 的每次纠正（这是最值钱的痕迹）；「一句话存档」给未来检索留钩子。
✓ 验收：点日历图标打开今天日记，点右上「插入模板」，四栏出现。
💡 不想手抄？下载 起步模板包（zip）：日记模板 + 人物 / 事件 / 习惯三个起步模板一次拿全，解压把 90-模板 等文件夹拖进库即可——第 2、3 节直接用得上。骨架（00-痕迹 / 10-本体 / 20-规则）还是建议自己建一遍，那正是本节的重点。
1.4 导入旧痕迹
  1. 把课前备的 2–3 份旧记录拖进 00-痕迹 文件夹（Obsidian 直接支持拖入 .md/.txt）。
  2. 每份开头补一行出处，格式随意但要有，例如：来源：2026-10 周报 · 原存于公司网盘
✓ 验收：00-痕迹 里至少有「今天的日记 + 2 份旧记录」。
1.5 写第一条像样的日记

用刚学的四栏，把今天写成一条 5 分钟日记——不用文笔，信息全就行。

✓ 验收：今天的日记四栏各至少 1 条。

本节排障表（4 个常见卡点）

下载慢 / 打不开官网官网偶发慢，稍等或换网络；安装包是本地安装，装好后不依赖官网。
找不到「核心插件」入口设置齿轮 → 左侧列表「核心插件 / Core plugins」；不要去「社区插件」找。
日记里没有「插入模板」按钮模板文件位置没填或填错路径，回到 1.3 第 2 步检查；路径里不要带文件名后缀。
旧记录拖进去是乱码原文件是 .docx 等格式，先另存为 .txt（UTF-8）再拖入。

2第 2 节 · 理：本体，谁是谁哪件事是哪件事（归一）

目标：从一周痕迹里找出反复出现的人和事，各归一成一条规范条目。约 55 分钟

2.1 认识双链
  1. 在任意笔记里输入 [[，会弹出笔记名候选——选中即成双链。
  2. 双链的意义：痕迹提「张老师」，本体里有 [[张老师]] 这个人，链接一挂，散的说法就有了锚点。
2.2 指令卡①：让 Copilot 找反复（零粘贴）
  1. 打开右侧栏 Copilot，聊天模式下拉切到 Vault QA（库内问答） 模式——Copilot 直接读你的全库，不用复制粘贴任何笔记。
  2. 对它说：
扫描我的 00-痕迹 文件夹里近 7 天的笔记（含旧记录）。 请找出：1) 反复出现的人（含不同称呼）； 2) 反复出现的事（含不同说法）； 各列一张表格，注明出处文件和日期。
  1. 发送，等它读完库出结果。
✓ 验收：Copilot 给出「人物表 + 事件表」，各至少 2 行，且注明了出处。
💡 名字起得别扭？回一句「换成更口语的中文名，10 字以内」。没装 Copilot 的同学才用旧方式：把指令卡①复制到 WorkBuddy / Claude / ChatGPT，手工粘贴近 7 天日记全文。
2.3 指令卡②：给一件事做归一
  1. 从事件表挑 1 件你真的关心的事，继续在 Copilot 里说：
就事件表里的「（这件事）」： 几种不同说法分别在哪些笔记里，请列出来； 给这件事起一个规范名称，列出「别名」， 并写清来龙去脉一段，方便我以后一眼认出它。
  1. Vault QA 模式下 Copilot 自己回痕迹里找说法，不用你贴。
✓ 验收：得到「规范名 + 别名 + 来龙去脉」一段 + 说法出处。
2.4 落库：建第一条本体条目
  1. 在 10-本体 新建笔记，标题用 AI 给的规范名。
  2. 正文结构照抄：
别名：小张那事 / 供应商的事 类型：事件 来龙去脉：（粘贴 AI 写的一段） 相关：[[张老师]] · [[2026-11-10]]
  1. 回到 00-痕迹 里那几条原始记录，把不同说法处加上 [[规范名]] 双链——归一完成。
✓ 验收：10-本体 有 1 条本体；痕迹里至少 2 处挂着它的双链。
2.5 照方抓药：建第一条人物本体
  1. 人物表里挑 1 个高频的人，同样用指令卡②归一（「同一个人的几种称呼」），在 10-本体 建人物条目（别名 + 关系 + 相关链接）。
✓ 验收：10-本体 至少「1 事件 + 1 人物」。

本节排障表（3 个常见卡点）

AI 说笔记太少找不出规律正常，痕迹少时 AI 只能列清单——照建本体即可；量是养出来的，不是补出来的。
AI 起的规范名很别扭回一句「换成更口语的中文名，10 字以内」，名字你说了算，AI 只是起草。
双链一多页面很乱链接挂「不同说法」出现的那几个字上即可，不必整句挂；乱就对了，本体层就是用来收敛乱的。

3第 3 节 · 用：规则，下次该怎么做（回流闭环）

目标：从经验沉出规则，把上下文喂给任意 AI，输出回流入库。约 40 分钟

3.1 指令卡③：沉淀规则（还是零粘贴）
  1. Copilot 保持 Vault QA 模式，对它说：
根据我近 2 周的日记和记录，总结 3 条我的工作习惯/偏好， 每条写成「以后遇到 __，就 __」的规则格式， 注明依据是哪几条笔记。
  1. 发送。它自己翻库，你只管看结果。
✓ 验收：得到 3 条「以后遇到 __，就 __」，且注明依据。
3.2 落库：建规则条目
  1. 在 20-规则 新建笔记 工作习惯 v1，把 AI 给的 3 条抄入，每条末尾加依据链接。
- 以后遇到要汇报的事，就只发结论三行，详情附后。（依据：[[2026-11-03]]） - 以后遇到周五下午，就先写周报框架再干别的。（依据：[[2026-11-07]]）
✓ 验收：20-规则 有 1 条规则笔记，含 3 条规则。
3.3 用起来：带着上下文问（Copilot 自带，免贴）
  1. 传统方式要先贴一大段「人物简况 + 规则」给 AI——Copilot 不用：你的本体和规则就在库里，它本来就看得见。
  2. Copilot 聊天模式（或 Vault QA）直接问：
参考我库里的 10-本体 和 20-规则， （提一个和这个人/规则相关的真实问题）
  1. 感受差别——AI 不再「说别人家的事」，回答里直接用你的称呼和规则。
✓ 验收：回答里用上了你库里的称呼/规则，不用你再解释。
💡 用外部 AI（WorkBuddy / Claude / ChatGPT）的同学才需要旧方式：新开对话先贴「以下是人物简况 + 规则，请记住，之后回答我都遵守：+（粘贴 10-本体 人物条目 + 20-规则 全文）」。
3.4 回流：让圈转起来
  1. 把这次 Copilot 回答中「有价值的新说法」写回今天的日记（第三栏或「今天」栏），前面加 [[本体名]] 或 回流： 标记。
  2. 四动作闭环至此走通：采集（日记）→ 构建（2 节归一）→ 检索（3.3 带上下文问）→ 回流（本步写回）。
🎯 课程的终点是习惯的起点：以后每天只做三个动作——写日记（采集）、见到重复就归一（构建）、Copilot 库内问 + 回流（检索/回流）。
✓ 验收：今天的日记里有一条「回流：」开头的记录。

本节排障表（4 个常见卡点）

AI 不遵守贴进去的规则回一句「请严格按上面的规则重新回答」；仍不行就换模型——这正是「末梢可换、上下文不换」的意义。
总结出的规则不像我删掉不像的，只留像的；规则宁缺毋滥，3 条留 1 条也比 3 条凑数强。
不知道哪些算「有价值的新说法」就一条标准：三个月后的你会想回来查它，就算。
指令卡贴给不同 AI 结果差很多正常，末梢有强弱；痕迹/本体/规则在你库里，换个 AI 重贴一遍即可，损失为零。

✓交付物自检（走之前 3 分钟）

交付物验收标准
三层库骨架00-痕迹 / 10-本体 / 20-规则 三文件夹 + 日记模板生效
本体条目至少 1 事件 + 1 人物，痕迹里挂有双链
规则条目20-规则 至少 1 条笔记、3 条规则（含依据链接）
闭环证据今天日记里有「回流：」记录一条

+课后选装 · 社区插件四强（安装量 Top 4）

定位：课上只装 Copilot，其余课后按需选装——先用 30 天养成上下文习惯，再让插件加杠杆。每个 5–10 分钟

插件解决什么怎么用上手
Copilot
github.com/logancyang/obsidian-copilot		AI 直连：在库内直接对话，免复制粘贴需自备 API Key（支持 Codex / Claude / OpenCode）→ 设默认模型 → 把手册第 3 节的规则笔记设为系统提示词——末梢进了库，上下文仍是你的
Excalidraw
github.com/zsviczian/obsidian-excalidraw-plugin		手绘白板：双链嵌入画布，把本体关系画出来社区插件市场搜 Excalidraw → 安装启用 → 新建 .excalidraw.md，把 10-本体的人物/事件关系画成一张图
Kanban
github.com/mgmeyers/obsidian-kanban		看板：20-规则外再建行动板，待办一眼看全社区插件市场搜 Kanban → 安装启用 → 新建看板，列按「待办 / 做中 / 已回流」分——接住日记第三栏的事
Tasks
github.com/obsidian-tasks-group/obsidian-tasks		任务聚合：全库待办自动汇总成清单，到期提醒社区插件市场搜 Tasks → 安装启用 → 新建一条查询 - [ ]，全库任务自动汇聚；配合日记用最顺
💡 选装顺序建议：Kanban / Tasks 先上（纯本地、零门槛），Excalidraw 看需求，Copilot 课前就装好了——它是「末梢」，任何时候换掉都不损失上下文。装哪个都不影响课上的指令卡用法。插件四强只是第一步：剪藏 / Dataview / Templater / 三大 AI 实战的完整进阶路线，见学员材料 《14 · 进阶路线图》。
📚 进阶路线上的插件同样附官网：Web Clipper 剪藏（github.com/obsidianmd/obsidian-clipper）· Dataview 数据查询（github.com/blacksmithgu/obsidian-dataview）· Templater 模板引擎（github.com/SilentVoid13/Templater）
