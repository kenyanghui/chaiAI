# rsi-tencentcloud-site

> 玄龙 AI 工作坊 2.3《腾讯云配置与域名上线》的课后交付物。
> **腾讯云子站点管家**：一张表管映射，一条命令查全站。

## 它是什么

给 WorkBuddy 装上一个「帮我盯着云上阵地」的技能。
你的每个网站（子站）长在哪台服务器、哪个 IP、开哪个端口——写进一张 `sites.json`，
之后说「我的站都通吗」，它逐个探测，一屏告诉你谁通谁不通；
说「查一下我的服务器」，它列出实例到期倒计时。

不是「让 AI 替我管服务器」，是「让 AI 按我的表查、写操作永远要我点头」。

## 它不是什么

- 不是自动运维器。**没有任何命令会替你销毁、重启实例。**
- 不是又一个控制台。它只做「查 + 记 + 开端口」三件事。
- 不是不填表就能用的东西。`sites.json` 不填，自查不知道查谁。

## 装

WorkBuddy → 技能 → 从文件夹导入：

```text
rsi-tencentcloud-site/
├── SKILL.md                 ← 入口：五件事、四条红线、排障表
├── sites.json               ← ★ 你的阵地地图，必须由你亲手填
├── pipeline/KEY-SAFETY.md   ← 密钥三原则 + 泄露应急
└── scripts/qcloud_api.py    ← 只用 Python 3 标准库
```

装完先做两件事：

1. 配密钥（见 SKILL.md「密钥放哪」一分钟版，或 KEY-SAFETY.md）
2. 把自己的站填进 `sites.json`（对照里面的示例行改）

## 用（最短路径）

```text
①「查一下我的服务器」     → 看实例、IP、到期倒计时
②「把新站记上」           → sites.json 加一行（域名+IP+端口+实例ID）
③「我的站都通吗」         → 全站自查 ✓/✗ 一屏看完
④「端口开了吗」           → 防火墙规则与表比对
⑤「开一下 8443」          → 打印规则 → 你看一眼 → 加 --yes 才执行（--cidr 可限定来源网段）
```

## 子站映射：sites.json 一行长什么样

```json
{
  "name": "chai-aibay",
  "domain": "chai.aibay.asia",
  "ip": "1.2.3.4",
  "port": 443,
  "instance": "lhins-xxxxxxxx",
  "icp": "已备案",
  "owner": "我",
  "next_review": "2026-12-15",
  "notes": "官网主站，续费提醒设 12-01"
}
```

一行 = 一个站。IP 忘了、端口是多少、备案到哪步、谁负责——**查表，不查聊天记录**。

## 失败了怎么办

排障表在 SKILL.md「失败了怎么办」——密钥、地域、防火墙、备案四大件。
都没命中时，把**报错原文**贴给 WorkBuddy，不要截图转述。
