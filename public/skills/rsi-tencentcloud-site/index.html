rsi-tencentcloud-site
腾讯云子站点管家

一张表管好「网站 ↔ 服务器 IP ↔ 端口」，交给 WorkBuddy：全站自查、到期提醒、端口放行。密钥永不入仓，写操作永远要你点头。

五件事

你对 WorkBuddy 说它做对应课上的
「查一下我的服务器」列实例：名称 / 公网 IP / 状态 / 几天到期第 3 节·买 Hermes
「把新站记上」sites.json 加一行：域名 + IP + 端口 + 实例30 天阵地计划
「我的站都通吗」逐站探测，✓ / ✗ 一屏看完交付 ② 公网可访问
「端口开了吗」拉防火墙规则，和表里期望端口比对第 3 节·防火墙
「开一下 8443」打印将要放的规则 → 你确认 → 加 --yes 才执行（--cidr 可限定来源网段）排障

装（三步）

  1. 一键下载 zip 包 解压（或下面逐个下载 5 个文件，按原目录结构放进文件夹 rsi-tencentcloud-site/）
  2. 配密钥（一分钟）：
mkdir -p ~/.tencentcloud && cat > ~/.tencentcloud/credentials <<'EOF'
[default]
secret_id = 把你的SecretId粘这里
secret_key = 把你的SecretKey粘这里
EOF
chmod 600 ~/.tencentcloud/credentials
  1. WorkBuddy → 技能 → 从文件夹导入，然后说：「查一下我的服务器」

只用子账号密钥（只读权限就够日常）；开权限步骤见 KEY-SAFETY.md。

四条红线

  1. 密钥永不入仓、永不进对话正文——只从凭据文件读，打印一律打码；贴进对话的密钥视同已泄露，不落盘不复用，先禁用再换新。
  2. 只用子账号密钥——日常只读；主账号密钥等于把家门钥匙整个交出去，告知风险后仍不代配。
  3. 唯一写操作是开端口，且要 --yes——销毁、重启、退费类永远不自动做；永不扩权（不加重启/销毁子命令，重启只指控制台），开端口优先 --cidr 限源。
  4. 表先于工具——sites.json 没登记的站不进自查；赶时间可走临时快查（先探，但标「表外临时」+附登记草稿）。
