# TF1-1 观察家记录表

> 来源：腾讯 ima 知识库「人才培养项目第 6 期」。由评分表图片 OCR 整理；不确定字符以〔?〕标注。原版图片见 `../files/TF1-1评分表.jpg`。

## 评分规则

分成3档（A-不合格，B-合格，C-优秀），若属于关键技能点，若得A档的即代表直接不能通关。
判断属于A档的，得0分。判断属于B档的，获得相应分值的60%得分。判断属于C档的，获得相应分值100%得分。

## 集体讨论补充（本次集体讨论，针对TF1-1做了以下完善与补充）

1. 增加"不值得拆"的判定红线：手册在 TF1-2 明确提到，若内容属于纯理念、老生常谈、过于简单这三种，观察家应行使一票否决权。在 TF1-1 引入此标准，可从源头提升拆书家的选材能力。
2. 〔?〕（OCR 缺失）
3. 强化"眼神交流"观察：TF1-1的目标之一是锻炼"当众表达能力"。【不允许在讲解中全程低头看稿。须有脸庞面向学习者、眼睛望向学习者的举动，至少一次。】
4. 细化A2的"具体"定义：很多新手拆书家在 A2 容易写出模糊的计划，这里观察家要注意判断"可观测的行为或动作"，也是判定B档与C档的关键分水岭。
