|---|---|
| 人＆职业〔?〕 | 拆书家是促进他人学习的人。类似于培训师、教育工作者职业。徒弟一上台拆书、看到学习者有收获就来劲，平时也爱琢磨怎么把书里的方法用起来，就和"拆书家/助他人成长"这条路合拍；若只愿意独自读书、不愿讲、不愿被看见，那么就错位了。拆书家有拆书变现的需求，现实中较难实现。 |
| 人＆岗位〔?〕 | 拆书家爱拆书、方向合拍，但第一次独立上场，控场、时间把控、临场应变还不到位；这是岗位技能暂时没长出来，靠演练和复盘后天就能补上的，就不用换方向。 |
| 人＆上级〔?〕 | 师父手把手教，多频次互动，徒弟积极晋级，双方就很顺；遇到徒弟习惯放养、徒弟却期待明确指令的，双方就出现节奏错位，徒弟容易卡住。敏感畏难时需要先托住情绪，这就是风格对上了双方匹配；如果师父〔?〕（该句 OCR 残缺）。 |
| 人＆群体〔?〕（03） | 拆书帮是公益的，有无偿的师徒〔?〕（"师徒徒"疑为"师徒制"）、有 3 级 9 拆晋级挑战制、慢慢的陪大家一起练习、互相观摩拆书、彼此打气，有同伴支撑更容易坚持；分舵里只剩自己一个人练、没有同侪交流，归属感弱，容易中途停下。 |
| 人＆组织〔?〕（04） | 〔?〕伴等（OCR 残句）；认同"陪伴赋能、助人成长、愿意长期投入"的人融入得顺；只想快速拿证、看重功利回报、不愿付出，就和分舵文化不合。 |
| 人＆环境〔?〕（06） | 徒弟自己工作极忙、分舵活动匮乏、分舵管理力量薄弱等，整体环境不支持，拆书家晋级就容易停滞。 |
