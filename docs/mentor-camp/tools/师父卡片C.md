## 降低物理门槛：来就好，不用做什么

拆书帮•师徒带教话术卡

**适用**：徒弟状态不稳，生活压力大，需要的是归属感而不是任务。

〔?〕（•~~~、~~。）

**你要做的事**

邀请徒弟参加分舵活动，但明确"没有任务要求"。

〔?〕（~~。）

**参考话术**

"下周六分舵有练武场，我们缺个帮忙拍照的人，你来吗？不用上台，就是帮大家拍拍，顺便蹭个饭。或者你就来坐着看也行，没人要求你做什么。"

〔?〕（～～、～～。）

**操作要点**

1. 给一个具体角色（拍照侠、学习者、现场工作伙伴），避免"你来就好"这种无边界邀请让人不知道如何接。
2. 会员日、吃吃喝喝的活动优先，降低心理成本。
3. 徒弟来了之后，不主动提练级，只让他感受到"这里的人和氛围"。
