## 流程节点

1. **学习《成长手册》战关卡的相关内容**
   - 卡点〔?〕（"一不懂一"）：看不懂/不理解。
   - 解决方法：或自己反复阅读，或找一些他人讲技能点的文章/视频课程来辅助学习。
   - 懂了 → 进入选书和拆页环节。

2. **选书和拆页环节**
   - 不符合本关卡要求 → 解决方法：向师父求助以及查看官网资料。
   - 符合本关卡要求 → 进入写稿环节。

3. **写稿环节**
   - 借助 AI，人机协作下写初稿；同时查阅官网同侪实录做参照，进一步理解本关技能点，如有必要可进行迭代修改晋级稿。
   - 稿子交给师父审查，师徒双方沟通，修定逐字稿。
   - 符合本关通关标准 → 进入记忆与准备环节；否 → 返回修改。〔?〕（"否"分支去向按流程惯例复原）

4. **记忆与准备环节：消化理解记忆晋级稿内容**
   - 晋级准备：
     1. 规划晋级时间。
     2. 自己练习/试讲。
     3. 准备相关晋级的物料、设备等，如：打印晋级稿、观察家记录表、计时器、录音设备、挂图纸（若有）。若是线上晋级要制作 PPT。
     4. 有学习者、观察家参加，有晋级场地（分舵组织）。
   - 符合 → 进入现场讲解的晋级环节。

5. **现场讲解的晋级环节**
   - 常见的没通关的原因有：
     1. 心态层。紧张、害怕被嘲笑等导致忘词或中断。
     2. 技能层。技能点本身存在硬伤。如拆页不对，学习目标没写等等。
     3. 逻辑层。对稿子的理解有偏差、讲解含糊、表达混乱等。
     4. 身份层。只以为自己是考试者，忽略了自己同时也是教授者/学习促进者。缺少必要的辅导。或者局限于自己懂了但不知道如何让学员懂。
   - 没通关 → 根据反馈意见做相应的处理。如：换拆书、重新写稿等。
   - 符合 → 整理实录，实录上传。
